# GLP-1/GIP/GCGR агонисты

Для изучения эволюции антагонистов GLP-1/GIP/GCGR: от борьбы с диабетом к рынку Lifestyle-медицины важный этап - анализ полученных их исследованиях данных. Как менялся фокус разработки препаратов группы GLP-1/GIP/GCGR: от лечения диабета 2 типа к ожирению и смежным показаниям? Проект анализирует открытые данные ClinicalTrials.gov и показывает динамику разработки по годам, препаратам и показаниям.

## Вопрос
Кто определяет клиническую активность по этим препаратам, когда она выросла и в какие показания расширяется?

## Данные
- Источник: ClinicalTrials.gov API v2, выгрузка 29.10.2026.
- Препараты: semaglutide (793), tirzepatide (308), orforglipron (53), cagrilintide (44), mazdutide (44), retatrutide (33), survodutide (29).
- После очистки (без отозванных исследований, годы 2010–2026): N исследований.

## Метод
1. Загрузка через API (`src/download.py`).
2. Разбор JSON в таблицу «одно исследование — одна строка» (`src/parse.py`).
3. Анализ и графики в `notebooks/analysis.ipynb`: число стартов по годам и препаратам, доли препаратов, показания (по ключевым словам в условиях исследования).

## Главные результаты
- Около 85% исследований стартовали с 2021 года.
- Semaglutide (60,5%) и tirzepatide (23,6%) дают около 84% всей активности; остальные препараты вместе около 16%.

## Ограничения
- Регистр показывает заявки на исследования, а не их результаты и не коммерческий успех. Это оценка активности разработки, а не размера рынка.
- Поиск по названию препарата включает комбинированные схемы (например, CagriSema для cagrilintide) и исследования, где препарат выступает сравнением.
- Для части исследований не указана фаза или дата старта.
- Год 2026 неполный; часть дат старта плановая.

## Как запустить
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src/download.py
python src/parse.py
```

Затем открыть `notebooks/analysis.ipynb`.
